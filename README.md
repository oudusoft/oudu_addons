# Oudu Addons for Odoo 13.0

This generated branch contains the official Oudu Software server modules for **Odoo 13.0**.

## Included modules

- [`oudu_base`](https://apps.odoo.com/apps/modules/13.0/oudu_base) — shared Oudu Software settings, instance identity and public capability manifest.
- [`oudu_desktop`](https://apps.odoo.com/apps/modules/13.0/oudu_desktop) — Oudu Desktop capability contribution, connection guide, report print policy and file upload controls.

Install `oudu_desktop` from this branch; Odoo installs `oudu_base` as its dependency. Both modules work in a standard browser, while the free [Oudu Desktop](https://desktop.oudu.top) client enables the native desktop capabilities.
