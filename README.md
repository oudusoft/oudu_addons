# Oudu Addons for Odoo 14.0

This generated branch contains the official Oudu Software server modules for **Odoo 14.0**.

## Included modules

- [`oudu_base`](https://apps.odoo.com/apps/modules/14.0/oudu_base) — shared Oudu Software settings, instance identity and public capability manifest.
- [`oudu_desktop`](https://apps.odoo.com/apps/modules/14.0/oudu_desktop) — Oudu Desktop capability contribution, connection guide, report print policy and file upload controls.
- [`oudu_iot`](https://apps.odoo.com/apps/modules/14.0/oudu_iot) — Oudu IoT host list, browser connection test, gateway shortcut and Point of Sale setup hint.

Install `oudu_desktop`, `oudu_iot` or both from this branch; Odoo installs `oudu_base` as their dependency. All modules work in a standard browser, while the free [Oudu Desktop](https://desktop.oudu.top) client enables the native desktop capabilities and [Oudu IoT](https://iot.oudu.top) devices connect through Odoo's own IoT Box and ePOS interfaces.
